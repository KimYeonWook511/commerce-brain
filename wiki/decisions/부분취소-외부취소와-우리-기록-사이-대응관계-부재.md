# 부분취소를 넣으니 드러난 것 — 외부 결제사 취소와 우리 취소 기록 사이에 대응 관계가 없다

부분취소 설계를 마치고 관점을 나눈 자동 검사를 돌렸을 때 동시성·실패 관점이 낸 치명 지적 두 건이 같은 뿌리에서 나왔다. 설계 시점에는 **미해결로 닫혔고**, 결제사 API 실측([[네이버페이-환불-api-실측-기록]])으로 답을 얻어 [[네이버페이-환불-이력-지목근거-보내기전-우리가-정하는-값]]에서 닫혔다.

## 문제 — 1:1이라서 성립하던 것이 1:N에서 깨진다

```
우리 기록:  취소 사건 3건 (사과 1개 / 배 1개 / 감 2개)
외부:       결제 건 식별자 하나
            ↑ 취소 요청에 우리 사건을 가리키는 값을 안 보냄
            ↑ 이력 조회는 목록을 다 주지만 우리 구현이 마지막 항목 하나만 보고 접는다
```

### (가) 어느 취소가 집행됐는지 판정할 수 없다

**외부는 이력을 목록으로 돌려주는데 우리 어댑터가 마지막 항목 하나만 골라** 승인/취소 판정 하나로 접는다. 즉 정보가 없어서가 아니라 우리가 버리고 있다.

```
사과 취소 → 성공
배 취소   → 결과 불확실로 남음
   ↓ 대사가 배 취소 사건을 후보로 잡음 → 이력 조회 → 마지막 이력은 "사과 취소" → "취소됨" 판정
배 취소가 집행되지 않았는데 성공으로 확정된다 → 환불 누락 + 사람에게 넘기는 조건에서도 빠짐
```

**"확정되지 않으면 사람에게 넘어간다"는 약속이 성립하지 않는다.** 반대로 판정이 "승인 유지"로 나오면 대사가 같은 부분 금액을 다시 취소 요청한다.

### (나) 재시도가 중복 집행될 수 있다

취소 요청에 우리 사건을 가리키는 값이 없다. 지금까지 중복 집행을 막아온 것은 **전액취소라서** 두 번째 호출이 "이미 취소됨"으로 돌아왔다는 사실이다. 다만 **결제사가 "잔액이 남아 있을 때 같은 금액의 두 번째 취소를 어떻게 처리하는가"는 우리가 확인한 것이 아니라 추론이다.**

도달 경로가 실재한다 — 외부 호출이 성공한 뒤 그 성공을 기록하는 단계가 낙관 락 충돌이나 프로세스 종료로 실패하면 사건이 요청됨 상태로 남고, 대사가 같은 금액을 다시 보낸다.

## 왜 놓쳤나

설계 단계에서 "대사가 다건 취소를 어떻게 지목하나"를 정하긴 했다. 그런데 그때 답한 것은 **우리 데이터베이스의 어느 행을 바꿀지**였다 — 결제 좌표로는 다건을 특정할 수 없어 사건 식별자로 바꾸기로 한 것이다.

**"외부에서 그 취소가 집행됐는지 판정하는 문제"는 완전히 다른 축인데 같은 질문으로 착각했다.** 그리고 설계 문서에 "후보 조회 방식은 바꾸지 않는다. 각 행이 독립적으로 후보에 잡힌다"고 적었는데 **그 문장은 맞지만 그다음이 틀렸다** — 후보로 잡는 것과 그 후보의 결과를 판정하는 것은 다른 단계다.

## 배운 것

- **외부 시스템과의 대응 관계가 "1:1이라서" 성립하던 것들을 목록으로 만들어야 한다.** 1:N으로 바꾸는 변경은 그 목록 전체를 건드린다. 이번엔 우리 쪽 조회 좌표는 목록에 넣었는데 외부 이력 판정은 못 넣었다.
- **"조회할 수 있다"와 "판정할 수 있다"를 구분한다.**
- **안전망이 무엇에 기대고 있었는지 확인한다.** "두 번째 취소 호출은 이미 취소됨으로 돌아온다"가 성립한 이유는 전액취소라 잔액이 0이 되기 때문이었다. **안전망이 사라진 것이 아니라 전제가 바뀌어 안전망이 아니게 됐다.**

## 당시 남긴 미해결 (그리고 어떻게 닫혔나)

- **특정 취소의 집행 여부를 무엇으로 판정할 것인가** → 이력 항목에 우리가 보낸 값이 되돌아온다는 실측으로 닫혔다.
- **재시도가 외부에서 두 번 집행되지 않게 하는 근거** → 같은 멱등키 재전송으로 닫혔다([[결과불명-재호출은-같은-멱등키로-새키-결론-뒤집힘]]).
- **"이 상태로 내보내도 되는가"를 아직 논의하지 않았다** — 돈이 두 번 나갈 수 있는 결함인데 완화책(부분취소 사건을 자동 재시도에서 빼고 바로 사람에게 넘기기 / 판정 방법이 정해질 때까지 기능 자체를 내보내지 않기)을 검토하지 않은 상태로 닫았다. **결과적으로는 실측이 먼저 도착해 판정 근거가 생겼지만, "위험한 상태인가"에 답하지 않고 넘어간 것은 그대로 남는 절차 공백이다.**
